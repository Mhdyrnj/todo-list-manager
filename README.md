# To-Do List Manager

A simple command-line to-do list manager written in Python.

## Features
- Add, remove, and view tasks
- Set a priority (High, Medium, Low) for each task
- Tasks are sorted by priority
- Save and load tasks from a CSV file

## How to run
python todo_list.py

## Concepts used
OOP (classes), file handling (CSV), dictionaries, error handling
